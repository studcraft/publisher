# Language

Two rules, and they are independent of each other.

- **Conversation** — respond in the language the user writes in, for every reply in the conversation, not just the first one.
- **Everything written down** — code, comments, docstrings, identifiers, documentation, and commit messages MUST be in English, regardless of what language the conversation is in.

So a session conducted entirely in Spanish still produces English commits and English comments.
